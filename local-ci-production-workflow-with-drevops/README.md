# Local-CI-Production workflow with DrevOps

A talk by Alex Skrypnyk on the DrevOps Drupal project template and how it keeps local development, CI and production identical. The template is known today as Vortex.

## Where it was presented

- **Event:** DrupalSouth Hobart
- **Date:** November 2019
- **Session page:** [drupalsouth.org](https://drupalsouth.org/events/drupalsouth-hobart-2019/sessions/local-ci-production-workflow-drevops)
- **Recording:** [YouTube](https://www.youtube.com/watch?v=zOsjoWzMvmc)
