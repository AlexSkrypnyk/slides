# Setup projects and onboard developers in minutes with Vortex

A talk by Alex Skrypnyk on how Vortex, the Drupal project template, sets up a new project and onboards a developer in minutes.

## Where it was presented

- **Event:** DrupalSouth Melbourne
- **Date:** March 2025

## Slides

- [Open the deck online](https://alexskrypnyk.github.io/slides/setup-projects-with-vortex/).
- To present from a local copy, open [index.html](index.html) in a browser and press <kbd>F</kbd> for fullscreen. The arrow keys move between slides.
- [setup-projects-with-vortex.pdf](setup-projects-with-vortex.pdf) is the PDF export.

The deck was built in Google Slides. `slides/` holds 1 image per slide exported from it. `index.html` shows those images in order.
