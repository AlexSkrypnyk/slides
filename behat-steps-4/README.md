# Behat Steps 4: Drupal 12-ready testing in 1 package

A talk by Alex Skrypnyk on Behat Steps 4.0.0, which brings Drupal Extension and Drupal Driver into a single library for Behat 4 and Drupal 12. It opens with an introduction to Behat and Gherkin, then covers the library's layers, capability-based backends and the move to 4.0.

## Where it was presented

- **Event:** Melbourne Drupal Meetup
- **Date:** November 2026
