# From Prompt to Pull Request

A talk by Alex Skrypnyk on a production-tested workflow for AI-assisted Drupal development. Developers plan the work, AI agents implement scoped tasks and every change ends as a tested, reviewable pull request.

## Where it was presented

- **Event:** DrupalSouth Wellington 2026
- **Date:** May 2026
